# 🍽️ 나의 레시피 노트

개인 레시피와 재료 창고를 섹션별로 관리하는 웹 애플리케이션입니다.

---

## 주요 기능

### 인증
- 아이디 / 비밀번호 로그인
- 회원가입 (실시간 유효성 검사, 비밀번호 강도 표시)
- 추후 카카오 / 네이버 간편 인증 연동 예정

### 홈
- 베이킹 / 음식 / 음료 3개 섹션 선택
- 섹션별 레시피 수, 재료 종류 요약 표시

### 레시피 관리
- 레시피 추가 / 수정 / 삭제
- 이모지, 카테고리, 분량, 오븐 설정(베이킹 전용), 재료, 단계, 메모 입력
- 카테고리 직접 입력 지원 (기타 선택 시)
- 단계별 개별 메모 작성 가능
- 재료 행 / 단계 행 동적 추가·삭제

### 재료 배수 계산
- 레시피 상세 조회 시 `+` / `-` 스테퍼로 배수 조절 (1배 ~ N배)
- 재료 텍스트에서 숫자를 자동 파싱하여 계산
- 정수, 소수(1.5), 분수(1/2) 모두 지원
- 분량(serving)도 배수에 맞게 함께 변경

### 재료 창고
- 섹션별 독립 관리 (베이킹 / 음식 / 음료 창고 분리)
- 재료명, 수량, 카테고리, 재고 부족 여부 관리
- 재고 부족 표시 시 대시보드에 카운트 노출

### 반응형 레이아웃
- `max-width: 1200px` 기준 중앙 정렬
- 브레이크포인트: `900px`, `600px`, `480px`, `400px`

## 화면 구성

```
로그인 / 회원가입
    ↓
홈 (섹션 선택)
    ↓
섹션 내부
  ├── 대시보드 (통계 + 최근 레시피)
  ├── 레시피 (목록 / 검색 / 카테고리 필터)
  └── 재료 창고 (목록 / 검색 / 카테고리 필터)
```

## DB 스키마 요약

```
users
  └─< recipes (user_id FK)
        └─< recipe_ingredients (recipe_id FK)
        └─< recipe_steps       (recipe_id FK)
  └─< pantry  (user_id FK)
  └─< categories (user_id FK, NULL = 기본 카테고리)

recipes >─ categories (category_id FK)
```

자세한 내용은 [`schema.sql`](./schema.sql) 참고.
