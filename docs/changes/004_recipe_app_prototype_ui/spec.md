# 스펙

## 목표

`prototype/recipe-app.html` 프로토타입과 동일한 화면 흐름·UI를 Next.js 앱에 반영한다.

## 시나리오 (정상)

1. **조건**: 앱 최초 진입
   **행동**: 로그인/회원가입 화면 표시
   **기대 결과**: `admin` / `1234` 등 mock 계정으로 로그인 가능

2. **조건**: 로그인 성공
   **행동**: 홈(베이킹·음식·음료 카테고리) 표시
   **기대 결과**: 섹션별 레시피·재료 개수 요약, 로그아웃 가능

3. **조건**: 카테고리 카드 선택
   **행동**: 섹션 화면(대시보드·레시피·재료 창고 탭) 진입
   **기대 결과**: 뒤로가기로 홈 복귀, 섹션별 데이터·카테고리·오븐 설정(베이킹만) 분리

## 범위 밖

- Supabase Auth·DB 연동 (기존 mock·연결 상태 표시 유지)
- 소셜 로그인 실제 연동
