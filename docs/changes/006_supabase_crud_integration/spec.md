# 스펙

## 목표

로그인한 유저가 화면에서 레시피·재료 창고를 Supabase DB로 **조회·저장·수정·삭제**할 수 있게 한다.

## 시나리오

1. DB 연결 + 마이그레이션 완료 → 회원가입 → 로그인 → 섹션 진입 → 목록이 DB에서 로드된다.
2. 레시피 추가/수정/삭제, 재료 추가/수정/삭제가 DB에 반영되고 UI가 갱신된다.
3. DB 미연결(`tablesReady` false) 시 기존 mock-data 동작을 유지한다.

## 범위 밖

- Supabase Auth 연동 (`auth.users`)
- 이미지 업로드
