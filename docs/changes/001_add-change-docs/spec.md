# 스펙

## 목표

코드·설정을 바꾸는 작업마다 `docs/changes/NNN_english_snake_summary/`에 `spec.md`, `analysis.md`, `changelog.md`를 남겨, AI(Cursor)와 개발자가 동일한 형식으로 이력을 추적할 수 있게 한다.

## 시나리오 (정상)

1. **조건**: 기능 추가·버그 수정 등으로 `src/**` 등이 변경된다.
   **행동**: 에이전트가 `docs/PORTABLE_AI_CHANGE_WORKFLOW.md`를 따른다.
   **기대 결과**: 다음 번호(`001`, `002`, …) 폴더가 생성되고 필수 3파일이 채워진다.

2. **조건**: 사용자가 질문만 하고 코드는 바뀌지 않는다.
   **행동**: 문서화 폴더를 만들지 않는다.
   **기대 결과**: `docs/changes/`에 불필요한 `NNN_` 폴더가 생기지 않는다.

## 예외

- **조건**: `.cursor/rules/**` 또는 `docs/changes/README.md`만 수정
  **기대 결과**: 새 `NNN_` 폴더 생략 (메타 문서만 변경)

## 범위 밖

- 과거에 이미 끝난 작업의 소급 상세 재작성 (별도 요청 시 `002_` 등으로 정리)
- 자동 Git 커밋·push (사용자 요청 시만)
